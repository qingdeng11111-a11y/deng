# LabCSV Check

**一个不用安装的实验 CSV 检查与交付小工具。**

选择 CSV → 确认时间列、测量列和单位 → 检查 → 导出包含原始文件、问题清单和重跑脚本的 ZIP。

适合传感器、课程实验、测试台的简单时间序列。纯浏览器本地处理，不需要 Python、GPU、API Key、账号或付费服务。项目是 **v0.1.1 实验原型**，并非完整实验数据管理平台。

本轮修复数字下溢、时间容差过宽与默认单位误用。项目定位及下一轮立项标准见 [复盘记录](RETROSPECTIVE.md)，实际测试范围见 [验证记录](VALIDATION.md)。

## 30 秒试用（Windows / Edge / Chrome）

1. 在 GitHub 页面点击绿色 **Code → Download ZIP**。
2. 在资源管理器里把 ZIP **全部解压**，不要直接在压缩包中打开。
3. 双击项目文件夹中的 **`index.html`**，用新版 Edge 或 Chrome 打开。保持旁边的 `.js`、`.css` 文件原位。
4. 点击 **「先试试内置问题样本」**，再点 **「开始检查」**。
5. 应看到 **8 条记录、2 个错误、4 个待复核提示、5 条涉及记录**。
6. 点击 **「导出交付 ZIP」**，解压 `labcsv-delivery.zip`，双击 `report.html` 查看完整报告。

无需运行 `npm install`。普通使用不需要 Node.js；只有开发测试或命令行重跑核验需要它。

## 检查自己的文件

选择 UTF-8 编码的 `.csv` 或 `.tsv` 文件，第一条记录必须是表头。支持 UTF-8 BOM、逗号/分号/Tab 分隔、带引号的分隔符、转义引号、多行引号字段、LF/CRLF。

示例：

```csv
time_ms,voltage_mV,note
0,1200,开始
1000,1250,正常
2000,,缺少测量值
```

按以下方式配置：

| 设置 | 本例填写 | 含义 |
|---|---|---|
| 时间列 | time_ms | 必须是数值型相对时间，不支持日期时间字符串 |
| 原时间单位 | ms | 输出统一为秒 |
| 测量值列 | voltage_mV | 只检查这一列测量值 |
| 原测量单位 | mV | 必须由你确认，不从文件名或表头猜测 |
| 输出单位 | V | 只能选择同一物理量的单位 |
| 期望采样间隔 | 1 | 单位固定为秒；留空则不检查间隔 |
| 下限 / 上限 | 0 / 5 | 使用输出单位；留空表示不限制 |

文件最多 **5 MiB、50,000 条数据记录、200 列**。超出限制会报错，不截断。一次处理一个文件。导入自己的文件或更改分隔符后，原时间单位和原测量单位必须主动选择，不使用默认单位；导入新文件也会清空阈值。内置合成样本使用已知单位与规则。

## 能检查什么

| 代码 | 级别 | 含义 |
|---|---|---|
| COLUMN_COUNT | 错误 | 列数与表头不一致，本记录不换算 |
| MISSING | 错误 | 选定的时间或测量值为空 |
| NOT_NUMBER | 错误 | 不是有限十进制数，例如 `NaN`、`Infinity`、公式文本 |
| OVERFLOW | 错误 | 单位换算产生非有限数值 |
| UNDERFLOW | 错误 | 非零十进制数在解析或纯比例换算时下溢为零，换算结果留空 |
| DUPLICATE_TIME | 待复核 | 时间与此前某条有效时间完全相同 |
| TIME_BACKWARDS | 待复核 | 当前时间比前一条相邻有效记录早 |
| TIME_GAP | 待复核 | 正时间间隔超过期望的 1.5 倍，且超出容差；可能缺测 |
| IRREGULAR_INTERVAL | 待复核 | 其他超出期望间隔 5% 容差的正时间间隔 |
| TIME_PRECISION | 待复核 | 时间数值相对期望间隔过大，双精度舍入误差估计达到 5% 容差；请复核原始时间 |
| OUT_OF_RANGE | 待复核 | 换算后的值超出用户设置的上下限（边界包含） |

间隔容差为 5%，另加舍入裕量 `min(2 × Number.EPSILON × max(|当前秒|, |前一秒|), 期望间隔 × 0.5%)`。舍入误差估计达到期望间隔的 5% 时另报 TIME_PRECISION，即使两个时间已舍入为相同值也会提示。这个估计不是精度证明；已在输入/换算中丢失的时间信息无法恢复。建议从仪器原始精度数据生成相对时间。无效时间或列数错误会断开相邻记录的间隔比较，避免跨过坏记录推断缺测；重复时间检测仍覆盖整个文件。重复时间用精确数值比较，不作近似合并。

提示不等于数据错误，例如回零、重新开始一次实验、真实突变都可能触发提示。**不会删除、插值、排序或自动修复任何记录。**

支持的单位组：`s/ms/min`（时间）；`V/mV`；`A/mA`；`Pa/kPa/MPa`；`m/cm/mm`；`K/°C/°F`；`1/%`。温度仅适用于**绝对温度**，不支持温差换算。无量纲 `1` 与百分数 `%` 按 `50%=0.5` 处理，不代表百分点。使用 JavaScript 双精度浮点数，不适合要求十进制精确计算的场景。UNDERFLOW 仅检测下溢为零，不保证非零次正规数的相对精度，也不解决温度偏置运算的消减误差。

## 交付包的内容

| 文件 | 用途 |
|---|---|
| `original.csv` | 原始字节完整保留。原文件名记录在 report.json；即使原文件是 TSV，也固定用此文件名，分隔符记录在 config.json |
| `normalized.csv` | 选定两列的换算结果：记录号、秒、测量值、输出单位、问题代码；**不是全表清洗结果** |
| `report.html` | 双击阅读的离线报告，包含全部问题 |
| `report.json` | 完整结构化分析结果、版本、原始文件名及哈希 |
| `config.json` | 本次实际使用的规则；列索引从 0 开始 |
| `manifest.json` | 其他包内文件的 SHA-256，不包含 manifest 本身 |
| `verify.cjs` | 包内保存的引擎快照，可离线重跑核验 |
| `README.txt` | 交付包快速说明 |

换算结果为空时，必须结合问题代码查看；原值仍在 `original.csv`。非选定列不进入 normalized.csv，但完整保留在原始文件中。`record` 从表头后的第一条数据记录开始计数，**不是物理行号**：带引号字段可能跨多行。

修改文件或规则后旧结果会失效，必须重新检查。界面最多显示 200 个问题；HTML/JSON 报告保留全部问题。

## 重跑与完整性核验（可选）

安装官方 Node.js 22 或更新的 LTS 版本后，在交付包所在文件夹打开终端：

```powershell
node verify.cjs
```

只运行你信任来源的脚本。未知来源交付包中的 `verify.cjs` 与其他可执行文件一样需要审查；不能因包内附有哈希就信任它。包内自检没有外部信任根，不提供数字签名、来源认证或防伪证明。

也可以从其他目录运行 `node "完整路径\verify.cjs"`。无需安装任何 npm 包。它会：

1. 核验 manifest 中每个文件的 SHA-256；
2. 使用包内引擎快照、原始数据和配置重新分析；
3. 比较完整结构化结果与 normalized.csv。

成功输出 `VERIFIED`，退出码为 0；不一致则非零退出。**核验成功仅表示可复现，不表示数据没有错误或实验结论正确。** manifest 不是数字签名；有人同时修改所有文件及 manifest 时，哈希不能证明数据真实或来源可信。

## 隐私与边界

- 应用没有网络请求代码、CDN、遥测、账号或在线模型；页面 CSP 禁止网络连接。文件只在当前页面内存中处理，刷新后需要重新选择。浏览器扩展与操作系统行为不在本项目控制范围内。
- 导出 ZIP 包含完整原文件。分享前由你检查隐私信息。原始 CSV 不会自动脱敏或过滤电子表格公式；未知来源原文件应谨慎在电子表格软件中打开。
- CSV 中的内容以文本显示；导出的 HTML 对动态文本转义，并禁用脚本。normalized.csv 只输出经过校验的数值和内置字段，不复制原始公式文本。
- 不支持 XLSX、GBK 自动识别、小数逗号、千分位、日期时间、任意单位、跨文件合并、统计异常检测、物理规律校验或仪器专有格式。
- 零问题只表示选定规则没有发现问题，不验证未选择的列。不能替代专业实验审核。

## 开发与测试

源码无第三方运行依赖。Node.js 22+：

```powershell
node --test tests/core.test.cjs
```

测试覆盖 CSV 格式边界、编码、单位转换、错误记录保留、时间轴规则、数值溢出、HTML 转义、ZIP CRC、跨目录重跑及篡改检测。示例数据全部是人工合成，没有真实用户数据。

```text
index.html / style.css / app.js   本地界面
core.js                          浏览器和 Node 共用的确定性检查引擎
zip.js                           简单 ZIP STORE 写入器（不压缩）
package.js                       交付包与重跑脚本生成
examples/                        合成数据及配置
tests/                           Node 内置测试框架
```

这是对“时间轴 + 显式单位换算 + 可复现交付”的小范围探索。没有把 Frictionless、Pint 或其他成熟库冒充成本项目实现；本版采用范围有限的自有规则，不声称替代这些库。复杂数据清洗可先考虑 [OpenRefine](https://openrefine.org/)，通用数据规范与校验可参考 [Frictionless](https://github.com/frictionlessdata/frictionless-py)。
